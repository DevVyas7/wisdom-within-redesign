# The Wisdom Bharat — Project Execution

## 1. Install Prerequisites

Install:

- Node.js
- npm

Verify the installation:

```bash
node --version
npm --version
```

## 2. Open the Project

Open the project folder in your code editor.

Then open a terminal in the project folder.

## 3. Install Dependencies

Run:

```bash
npm install
```

Wait for the installation to complete successfully.

## 4. Start the Project

Run:

```bash
npm run dev
```

The terminal will display a local URL.

Open the displayed URL in a web browser to view the website.

## 5. Create a Production Build

After making changes, the project can be checked with a production build:

```bash
npm run build
```

The build should complete without errors.

## Execution Flow

```text
Install Node.js & npm
        ↓
Open the project folder
        ↓
Open terminal in the project folder
        ↓
npm install
        ↓
npm run dev
        ↓
Open the local URL
        ↓
Run npm run build when required
```
